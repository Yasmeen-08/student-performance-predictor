# Student Performance Predictor

A machine learning web app that predicts a student's final score from study hours, attendance, previous exam score and assignments done.

## Live app
https://student-performance-predictor-vvywbqkfjkpgc5kiybteab.streamlit.app/

## Tools used
- Python
- scikit-learn (Linear Regression)
- Streamlit
- pandas

## Note
The data used is sample data generated by the program.
